# MyBatis / iBATIS

iBATIS (later renamed MyBatis) was a popular SQL mapping framework, often used as a lighter alternative to Hibernate in the SSH era or with Spring.

## Key Concepts

- XML mapper files with SQL statements
- Parameter and result mapping
- SqlMapClient (iBATIS) or SqlSession (MyBatis)

## Setup

JDK + iBATIS 2.x or early MyBatis + database driver.
Often integrated with Spring via SqlMapClientFactoryBean or later SqlSessionFactoryBean.
