# Authorware

Macromedia Authorware (later Adobe) — iconic flowchart-based multimedia authoring tool, very popular for CBT (computer-based training) and educational software in the 90s/early 2000s.

## Key Concepts

- Icons on a flowline: Display, Wait, Erase, Motion, Interaction, Calculation, etc.
- Variables and functions in Calculation icons.
- Interactions: buttons, hot spots, text entry, etc.

## Sample Calculation Icon Snippet

```
Box(1, 100, 100, 200, 200)
result := 10 * 5
```

## Setup

- Authorware 5/6/7 from WinWorldPC or archives.
- Runs on Windows 95/98/XP.
- Publish as EXE or web package.

Once-popular for rapid multimedia; declined with Flash, HTML5, and modern tools.
