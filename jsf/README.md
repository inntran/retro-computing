# JSF (JavaServer Faces)

Component-based Java web framework (part of Java EE). Popular in the mid-2000s for enterprise apps.

## Typical Stack

- Java EE 5 / 6 server (GlassFish, JBoss, or Tomcat + Mojarra/MyFaces)
- Facelets (XHTML) for views
- Managed beans for backing logic

## Setup

1. Use a Java EE application server or Tomcat with JSF libraries.
2. Configure `faces-config.xml` (older style) or annotations.
3. Deploy a web application containing `.xhtml` pages and beans.

Largely superseded by Spring Boot + Thymeleaf, or other modern front-end approaches.
