# Crystal Reports

Very popular reporting tool in the 90s and 2000s, especially with Visual Basic, Classic ASP, and early .NET.

## Typical Use

- Design reports visually (bands, groups, formulas).
- Connect to Access, SQL Server, Oracle, etc.
- Embed in VB6, ASP, or .NET applications via the Crystal Reports runtime / viewer.

## Setup

1. Install Crystal Reports (version 8.5 / 9 / 10 / XI era from archives or old media).
2. Design a `.rpt` file.
3. In VB6 or ASP, use the Crystal Reports ActiveX / COM components to load and display the report.
4. For .NET, use the Crystal Reports for Visual Studio redistributable of that era.

Still used in some legacy systems; largely replaced by SSRS, Power BI, JasperReports, etc.
