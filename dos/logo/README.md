# Logo Language

Educational turtle graphics language popular in the 80s/90s.

## Sample (IBM Logo / Dr. Logo style)

```
TO SQUARE :SIZE
  REPEAT 4 [FD :SIZE RT 90]
END

SQUARE 100
```

## Setup

- Use DOSBox with IBM Logo or MSWLogo (Windows 3.x).
- Or FreeDOS + available Logo packages from Simtel archives.

Place Logo interpreter files in a subfolder or mount alongside the DOS image.
