# Mario 1994 (Mike Wiering) - Turbo Pascal Source

Open source Super Mario Bros. clone written in Turbo Pascal by Mike Wiering in 1994.

Original source available from the author (freeware with source).

## Build

Requires Turbo Pascal 6/7 in DOS environment:

```
TPC /M /L MARIO
```

See `https://github.com/skrzyp/mario-and-luigi` or original site for full source.

## Run

In DOSBox / DOSBox-X with Turbo Pascal installed on the virtual HDD.

Copy sources into the DOS image after install.
