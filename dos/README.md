# DOS Environments

Experiments with MS-DOS 6.22, FreeDOS, and development tools.

Recommended: DOSBox-X for virtual hard disk images + full DOS install.

## Subfolders

- `msdos622/` — Full MS-DOS 6.22 install on virtual HDD
- `freedos/` — FreeDOS install
- `turbo-pascal/` — Turbo Pascal samples
- `logo/` — Logo language examples
- `mario-1994/` — Open source Mario 1994 (Mike Wiering Turbo Pascal)
