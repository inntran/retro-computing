# DOS Graphical / Text UI Libraries

## Turbo Vision

Borland's TUI framework used in Turbo Pascal / C++ IDEs and many apps.

- Included with Turbo Pascal 6/7 and Borland C++.
- Character-mode windows, menus, dialogs.

Modern ports exist (magiblot/tvision, Free Vision).

## Norton Utilities / Norton Commander style

Norton tools used custom TUI. Many file managers (e.g. DOS Navigator) used Turbo Vision or similar.

## PC Tools

Central Point PC Tools — another classic DOS utility suite with its own interface style.

## Setup

Install Turbo Pascal with Turbo Vision units on the DOS virtual HDD.
Study sample TV programs or port existing ones.
