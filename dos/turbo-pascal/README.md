# Turbo Pascal

Classic Borland Turbo Pascal 5.5 / 6 / 7 for DOS.

## Quick Hello World

```pascal
program Hello;
begin
  writeln('Hello from Turbo Pascal');
end.
```

Compile in the IDE (F9) or with `TPC HELLO`.

## Setup

1. Install full MS-DOS or FreeDOS on virtual HDD (see parent folders).
2. Copy Turbo Pascal installation files into the image.
3. Run `TURBO` or `TPX`.

Many people run it successfully directly in DOSBox's built-in environment without full DOS, but full install matches the requested virtual HDD approach.
