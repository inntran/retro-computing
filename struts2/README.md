# Struts2

Popular MVC framework in the mid-to-late 2000s (successor to Struts 1). Used interceptors, OGNL, and convention or XML configuration.

## Key Concepts

- Actions (POJOs with execute method)
- Interceptors (validation, workflow, etc.)
- Result types (JSP, redirect, etc.)
- Often combined with Spring and Hibernate (SSH2)

## Setup

JDK 1.5+ + Tomcat + Struts2 JARs + `struts.xml`.
