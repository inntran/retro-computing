# Windows XP Experiments

Preferred Windows guest for lower idle CPU compared to Win9x.

## Subfolders

- `classic-asp/` — Traditional ASP with ADO database connection example
- `netfx20/` — .NET Framework 2.0 console sample
- `netfx35/` — .NET Framework 3.5 sample (LINQ)
- (VB6 can be added here later)

Run on TrueNAS KVM or local VM. Install IIS for ASP, .NET redistributables as needed.
