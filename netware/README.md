# Novell NetWare Clients (DOS and Windows)

## DOS Client

- NETX (older) or VLM / Client32.
- IPX/SPX primarily; later IP support.
- Config via NET.CFG.

## Windows Client

- Client32 for Windows 3.x / 9x / NT.
- Install from Novell Client CD or archives.

## Setup Notes

1. DOS: Boot to DOS, run INSTALL from client media.
2. Windows: Run SETUP.EXE or WINSETUP.
3. For testing, a NetWare server VM is ideal (complex) or use historical client files from archives.

NetWare was dominant before TCP/IP and Active Directory took over.
