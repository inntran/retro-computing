# ASP.NET (Web Forms era)

Classic ASP.NET Web Forms (1.1 / 2.0 / 3.5), the dominant Microsoft web technology before MVC.

## Key Concepts

- `.aspx` pages with code-behind
- Server controls (`<asp:Label>`, `<asp:GridView>`, etc.)
- Postback model and ViewState
- Often used with ADO.NET or early Entity Framework

## Setup

Visual Studio 2005/2008 + .NET Framework 2.0/3.5 on Windows XP/2003/2008. IIS or built-in development server.
