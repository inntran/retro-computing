# ColdFusion

Adobe (formerly Allaire/Macromedia) ColdFusion was a popular rapid web development platform using CFML (ColdFusion Markup Language).

## Key Features

- Tag-based language (`<cfquery>`, `<cfoutput>`, `<cfif>`, etc.)
- Easy database access
- Often used for intranet and business applications in the late 90s / 2000s

## Setup

ColdFusion Server (MX / 7 / 8 era) on Windows or other platforms. Deploy `.cfm` files.
